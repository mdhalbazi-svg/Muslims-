# Release readiness

Before Play Console upload:
- Complete all religious content and scholarly reviews.
- Integrate and test AdMob only if desired.
- Set the current Play-required target SDK at release time.
- Configure a stable application ID and signing key.
- Verify SHA-1/SHA-256 fingerprints.
- Complete privacy policy, Data safety, ads declaration, content rating, app access, and store listing.
- Test on physical Android devices, including offline mode and RTL layouts.
- Verify APK/AAB signatures and Play Console pre-launch report.

No Play approval or production build success is guaranteed by this source ZIP.
